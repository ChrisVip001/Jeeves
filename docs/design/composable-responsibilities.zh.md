# 从主对话安排周期委托

[English](composable-responsibilities.md) | 简体中文

用一句话描述时间或事件、想要的结果和接收位置。Jeeves 会提交一张待确认的卡片。之后可以在聊天里修改、暂停或恢复同一项委托。「我的工作」显示确认过的定义和运行记录。新账户没有预置周期委托。

## 组合一项委托

可选触发方式包括具体时间、确认后延迟、固定间隔、日历计划和签名来源事件。确定性动作可以生成提醒、用固定参数从已批准来源汇总摘要、核验已保存的证据，也可以检查结构化记录。读取动作调用一个已启用的只读工具，把结构化结果作为文本返回。摘要可列出多个来源，每个来源都是已批准的只读工具加固定参数；早期的 calendar/task/mail 命名来源继续兼容。记录动作可检查收到的事件、有效期内的最近一条签名记录，也可在每次运行时从已批准的只读工具取数后判定。例如，说「最近的读数低于指定数值时，在这里提醒我」。审阅卡上会显示确切的工具与参数、比较条件、单位或字段，以及接收位置。`capabilities` 结果会列出所有可用只读工具及其输入 schema。

模型起草可以引用已经审阅的已安装技能版本。技能提供可复用的处理指令。来源与连接器由用户单独开启。Jeeves 可以通过自然语言组合已启用的能力。新增服务的认证、来源协议或外部写操作需要实现连接器。使用已启用能力组合新委托，无需改动执行引擎。

结果可以发到主聊天，也可以保留为私密草稿。可选的投递适配器通过同一份能力目录公开目的地，复用审批和回执机制。随产品提供的飞书集成须由用户主动开启。每次外发都须审批确切内容和收件人，并在发出前再次核对当前版本和连接器权限范围。

## 执行与恢复

时间与签名事件都为每次触发记录唯一唤醒。定时器只在 15 分钟窗口内补最近一次。签名事件的游标更新与唤醒入账在同一事务中完成。重复事件或时间槽不会增加投递。委托修订后，未结算的唤醒转入待核对。执行租约到期或中断也会留下待核对记录。运行记录显示阻塞、跳过、投递和中断。预览只读，不推进时钟和事件游标。[Runtime 协议](../protocol.zh.md)

## 升级后的已有委托

| 已保存的委托 | 升级行为 |
| --- | --- |
| 研究周报 | 通用证据动作保留七天窗口与已授权网址。共享定时器识别 Runtime 本地时区，已保存的收件人转成连接器目的地，历史草稿和回执仍可查看。 |
| 晨报 | 旧定时和来源保留在待确认的私密摘要中。委托暂停，用户确认输出、来源与接收位置后可恢复。 |
| 比价 | 旧监控暂停，保留报价观测、任务历史、阈值修订和回执。连接结构化来源后，可确认新的条件，并按需要核对币种、商品标识和运费。 |

## 验收

- `just smoke-recurring-work` 使用隔离的 Web 账户与脚本模型，创建、预览、修改和暂停日历及任务摘要。独立的报销邮件用例配置签名来源，匹配财务发件人和 PDF 附件，只发出一条带来源的提醒。条件不匹配、重启后重放或停用后收到新事件都不会增加投递。事件执行没有模型请求。
- `just eval-morning-briefing` 与 `just smoke-price-watch` 升级 v14 数据库，在重启前后检查暂停状态和保留的历史。后者也验证共享定时器如何对近期签名记录执行数值比较。
- `just smoke-weekly-report` 覆盖旧注册入口、确切内容审批、回环飞书接收端、预算检查和崩溃对账。
- [真实模型报销邮件验收](../../evals/results/recurring-event-live.json) 记录合成邮件元数据对应的自然语言工具提议。[配置入站事件来源](../configuration.zh.md)
