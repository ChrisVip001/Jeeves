# Jeeves 设计系统（DESIGN.md）

Mac 的助理与 Cowork、桌面网页和 iPhone 网页使用同一套**黛青**。颜色取自[「今天」预览的黛青方案](today-preview.html#p=teal&f=sans)，标题与正文沿用苹方无衬线字体。组件通过共享样式表引用颜色变量。

文字规范见 [voice.zh.md](voice.zh.md)，主聊天和任务会话的关系见[主入口设计](main-entry.zh.md)。

## 1. 气质与原则

- **亮色是默认，暗色是同等公民**。两套都按同一组 token 设计，跟随系统的
  `prefers-color-scheme` 切换，暗色不是亮色的反色。
- **中性灰表面**。画布与侧栏略带青色，主文本使用青黑或浅灰绿。
- **克制单色 + 唯一强调色**：界面近乎单色，黛青用于主操作、活动态、链接和品牌标记。
  琥珀色只表示"需要你"，不做装饰。
- **层级靠亮度台阶**：画布 → 侧栏 → 卡片，每层只差一点亮度，用细线分隔，不用重阴影。
- **大留白**：对话单列居中（max-width 760px），信息密度靠排版层级而非边框分隔。
- **微动效**：淡入、呼吸点、150–250ms 的 ease-out 过渡；不弹跳、不抢戏。

## 2. 色彩 Token

| 用途 | 样式变量 | 亮色 | 暗色 |
|---|---|---|---|
| 画布 | `--bg` | `#f1f2f0` | `#121615` |
| 侧栏 | `--bg-panel` | `#e7e9e6` | `#181d1c` |
| 卡片和输入框 | `--surface` | `#f9faf8` | `#1e2423` |
| 悬停表面 | `--surface-hover` | `#eef0ed` | `#242b2a` |
| 分隔线 | `--line` | `#dcdfdb` | `#29302f` |
| 主文本 | `--text` | `#1c2220` | `#e3e8e5` |
| 次要文本 | `--text-2` | `#4f5856` | `#9fa9a6` |
| 元数据 | `--text-3` | `#5e6865` | `#85908d` |
| 主操作和品牌标记 | `--accent` | `#1d6563` | `#6cb5ae` |
| 主操作悬停 | `--accent-hover` | `#175553` | `#80c2bb` |
| 主按钮文字 | `--on-accent` | `#ffffff` | `#0c1413` |
| 等待决定 | `--warn` | `#8c5b0c` | `#dba646` |

主按钮文字与按钮底色的对比度为亮色 6.79∶1、暗色 7.87∶1；元数据文字与侧栏的对比度为 4.72∶1 和 5.17∶1。

## 3. 字体

- 栈：`"PingFang SC", "Noto Sans SC", system-ui, -apple-system, "Segoe UI", sans-serif`
- 等宽：`ui-monospace, "SF Mono", Menlo, monospace`（代码、命令、路径）
- 正文 **14px / 1.65**；辅助 13px；元数据 12px；卡片标题 14px/600
- 权重只用三档：400（阅读）、500（强调/导航）、600（标题/按钮）
- 不使用粗体 700；标题不加字距，正文不加负字距（中文无此需求）

## 4. 间距与圆角

- 基数 8px；实际使用 4 / 8 / 12 / 16 / 24 / 32
- 圆角：控件 8px；卡片 12px；大浮层 16px；胶囊 999px
- 阴影：浮层使用随外观切换的 `--shadow-overlay`。

## 5. 组件速查

- **主按钮**：`--accent` 底、`--on-accent` 字、8px 圆角、hover `--accent-hover`。
  一张卡片最多一个主按钮，放在右侧
- **次按钮**：透明底 + `--line` 边、`--text` 字
- **任务行**：状态点 + 标题 + 一行 `--text-3` 进度短语；选中时 `--surface-hover` 底。
  状态点：琥珀 = 需要你，黛青 = 进行中，`--text-3` = 常驻待命
- **汇报卡片**：12px 圆角，`--surface` 底 + `--line` 边。结构固定为
  结论标题 → 两三句正文 → 一行证据链接 → 最多两个按钮。
  待确认卡片加 3px `--warn` 左缘；纯通知卡片没有按钮
- **消息流**：单列；用户消息右对齐 `--surface` 块，Jeeves 的消息通宽无框
- **输入区**：单块圆角容器（textarea + 附件 + 发送），聚焦时边框转 `--accent`

## 6. 布局

- 桌面：左栏 232px（品牌 / 任务栏）+ 主区（对话单列居中）；任务详情抽屉从右滑入
  （fixed，宽 min(420px, 92vw)），不挤压对话列
- 移动（<720px）：任务栏收进顶部的"任务"入口，抽屉全宽；待确认卡片的按钮固定在
  拇指可达的底部；触控目标 ≥ 44px

## 7. Do / Don't

- ✅ 引用 token；亮度分层；细线结构；主区留白；状态用"点 + 灰字"
- ❌ 在组件中写死颜色；彩色大底块；实色粗边框；卡片套卡片；
  渐变横幅；弹跳动画；每个按钮都做成主按钮；用琥珀色做装饰
