# 实现原理

[English](README.md) | 简体中文

按模块讲 Jeeves 是怎么搭起来的：每一层做什么、为什么这样设计、改动该落在哪里。每章只写当前的实现；
它不是 API 参考（契约见[协议](../protocol.zh.md)），也不复述代码已经能看出来的控制流。读者能读 Rust，
想改行为、加工具或 provider，或想弄清一轮对话做了什么。

## 章节

章节顺序就是依赖顺序：后一章建立在前面几章之上。

| 2 | [状态](02-state.zh.md) | `state.db`、迁移、账本、事实与检索、队列 |
