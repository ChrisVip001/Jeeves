# Weekly review

Draft a short review of the last seven days. Read and summarize; never change anything outside the outbox.

1. `memory(action=search)` for recent decisions, projects and commitments; check the todo list and open tasks.
2. Group what you found: done, still open, dropped. Name what is blocked and on whom.
3. Write at most 15 lines: what mattered, what is open, three concrete suggestions for next week.
4. Save the draft with `send_message` (it only writes a draft to `<home>/outbox/`) and reply with the same text.

If memory holds nothing from the week, say so in one line instead of inventing activity.
